# SF Resource Calc

Статический калькулятор для GitHub Pages (HTML/CSS/JS) с двумя режимами:
- `Матоварка`: расчёт ресурсов для производства выбранных материалов.
- `Преобразование`: расчёт максимального выхода ресурсов/материалов из имеющихся запасов с учётом КПМ.

Все значения вводятся и выводятся в трлн.

## Локальный запуск

1. Откройте терминал в папке проекта:
   ```bash
   cd /Users/dev3l/Projects/personal/sf-resource-calc
   ```
2. Поднимите локальный сервер:
   ```bash
   python3 -m http.server 8080
   ```
3. Откройте:
   [http://localhost:8080](http://localhost:8080)

## Публикация на GitHub Pages

1. Загрузите файлы репозитория на GitHub.
2. В репозитории откройте `Settings` → `Pages`.
3. Выберите `Deploy from a branch`.
4. В качестве ветки выберите `main` (или вашу рабочую), папка `/ (root)`.
5. Сохраните настройки и дождитесь ссылки на опубликованный сайт.
